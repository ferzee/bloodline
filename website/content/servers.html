For server owners

Host a world where families last for generations

Bloodline Chronicles runs on the server. Players can join with normal Minecraft; those who install the mod themselves get the illustrated Chronicle and parchment scrolls.

  • Minecraft 26.3
  • Fabric Loader 0.19.5+
  • Fabric API
  • Java 25

IInstalling

The mod needs Fabric Loader and Fabric API for Minecraft 26.3, and Java 25.

  1. 1

    Install Fabric Loader on the server

    Download the Fabric installer from fabricmc.net and run it in your server folder, or use the server launcher it offers there.

    Terminal
    java -jar fabric-installer.jar server -mcversion 26.3 -downloadMinecraft
  2. 2

    Add the mods

    Put Fabric API and Bloodline Chronicles in the mods folder.

    Server folder
    server/
├── mods/
│   ├── fabric-api-[version].jar
│   └── bloodline-chronicles-[version].jar
├── config/
└── fabric-server-launch.jar
  3. 3

    Start the server

    The first start creates the settings file, config/bloodline.json. Players who join get a house, a character and the Chronicle straight away.

    Terminal
    java -Xmx4G -jar fabric-server-launch.jar nogui
✦

Players without the mod

Anyone with normal Minecraft 26.3 can join. They see the Chronicle as a plain written book and choices as Minecraft's own dialog windows. Players who install the mod (with Fabric API) get the illustrated book and parchment scrolls, and see the mod's text in their own language once translations exist.

Singleplayer

Put the same two files in the mods folder of a Fabric profile in your launcher, or install from Modrinth or CurseForge with their apps. Every new world starts with your first house.

Inns and crypts

Roadside inns, barrow crypts, wayside shrines and fallen manors generate in newly explored land, so on an existing world players have to travel to new chunks to find them. Village inns work everywhere: an innkeeper appears at any village bell.

IIThe settings file

All settings live in config/bloodline.json. It is rewritten on every start, so settings added in later versions appear with their default values; invalid values fall back to the defaults. Changes apply the next time the world starts.

IIICommands

Players don't need commands: the Chronicle, the scrolls and the buttons in chat do nearly everything. Only inviting players, removing members and passing on leadership need a command for now. The rest are for players who prefer typing, and for operators.

For every player

CommandWhat it does
/bloodlineYour house, character, traits, members and renown.
/bloodline questsYour duties and quests with progress.
/bloodline tree [player]The family tree.
/bloodline info <player>Another player's house.
/bloodline chronicleA new copy of the Chronicle.
/bloodline heir <1-3>Choose your heir after a death.
/bloodline event [accept|decline]See or answer a family event waiting for a choice.
/bloodline sacrificeStart the Sacrifice.
/bloodline accept keep|fresh
/bloodline decline		Answer an invitation to another house.
/bloodline leaveLeave your house and found a new one.

For the head of a house

CommandWhat it does
/bloodline oath [sword|deep|hearth]See or swear the house's oath.
/bloodline house <name>Rename the house.
/bloodline invite <player>Invite a player into the house.
/bloodline remove <player>Send a member away.
/bloodline head <player>Pass leadership on.

For operators

These need operator permission (level 2).

In game or console
# Wipe a player's family, so they start over with a new house
/bloodline admin reset <player>

# Find the nearest roadside inn or barrow crypt
/locate structure bloodline:roadside_inn
/locate structure bloodline:crypt
/locate structure bloodline:shrine_temperate   # or shrine_cold, shrine_warm
/locate structure bloodline:fallen_manor

For testing, there are also debug commands:

CommandWhat it does
/bloodline debug completeFinish your newest quest.
/bloodline debug renown <amount>Add (or take) renown.
/bloodline debug event <type>Start a family event: sickness, restless, feud, wedding or cousin.
/bloodline debug ageCount your character as having lived a full life.
/bloodline debug championSpawn a test champion.
/bloodline debug manor [clear|reset]Inside a manor: see its progress, drive the occupants out at once, or start it over (the claim stays).
/bloodline debug crypt [reset]Inside a crypt: see its answer and progress, or start it over.
!

Grave command

/bloodline admin reset can't be undone: the player's family, ancestors and branch of the house are forgotten. Back up your world folder first.

IVSaves and accounts

Every family is stored in the world's save, linked to the player's Minecraft account, so it survives name changes. Families belong to that world: another world or server has its own. On offline-mode servers, families follow the player's name instead.
