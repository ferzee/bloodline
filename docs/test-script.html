Bloodline Chronicles · Fabric · Minecraft 26.3

Test script

Run this after every update. Use Full test before a release and Quick check after a small change. Mark each test Works, Broken or Skip (not possible this time), and note what you saw when something breaks. At the end, copy the report and paste it to Claude. Your marks stay in this browser until you clear them.

    Before you start

    Start the game from a terminal. The second client is only needed for the multiplayer tests (open your world to LAN in the first, join it from the second).

    cd ~/Dev/Bloodline && JAVA_HOME=/opt/homebrew/opt/openjdk@25/libexec/openjdk.jdk/Contents/Home ./gradlew runClientthe game, as player "Fersy"
    cd ~/Dev/Bloodline && JAVA_HOME=/opt/homebrew/opt/openjdk@25/libexec/openjdk.jdk/Contents/Home ./gradlew runClient2a second player, "Friend"

    Create a new world in Survival with cheats on for each round. Handy commands:

    /bloodline debug completefinishes your newest quest
    /bloodline debug renown 50adds renown (negative takes it)
    /bloodline debug agecounts as a full life, so traits pass on
    /bloodline debug event feudor sickness, wedding, cousin, restless
    /bloodline debug cryptinside a crypt: its answer and progress
    /bloodline debug championspawns a test champion
    /locate structure bloodline:cryptthen click the coordinates
    /locate structure bloodline:roadside_innthe nearest roadside inn
    /locate structure #minecraft:villagethe nearest village inn
    /summon zombie ~3 ~ ~something to die to or kill
    /time set 18000midnight; on day 1 the moon is full
    /give @s emerald 64for jobs, rumours and the steward
    /give @s iron_swordfor the heirloom tests
    /give @s golden_applecures sickness
    /difficulty peacefulfor the Peaceful tests; set back to normal after
    /gamemode survivaldeaths and drops need Survival
